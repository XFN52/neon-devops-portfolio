# Neon DevOps Portfolio 🚀

Современный, высокопроизводительный сайт-портфолио, выполненный в стиле Cyberpunk/Neon. Проект разработан для демонстрации навыков DevOps-инженера, системного архитектора и разработчика.

![Preview](https://raw.githubusercontent.com/your-username/my_site/main/preview.png) *(замените на реальный скриншот после публикации)*

## ✨ Особенности

- **Cyberpunk Aesthetics**: Глубокий черный фон с неоновыми акцентами (Cyan, Purple, Green).
- **Interactive Terminal**: Контактная форма, стилизованная под терминал Linux.
- **Smooth Animations**: Плавное появление элементов при скролле и глитч-эффекты для текста.
- **Responsive Design**: Полная адаптивность под мобильные устройства и десктопы.
- **Tech Stack View**: Наглядная визуализация используемых технологий и системных модулей.

## 🛠 Технологический стек

- **Frontend**: React 19, TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Custom CSS + Framer Motion (через RevealOnScroll)
- **Deployment Ready**: Оптимизированная сборка и готовность к CI/CD.

## 🚀 Быстрый старт

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/my_site.git
   cd my_site
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Настройте переменные окружения:**
   Создайте файл `.env.local` на основе `.env.example`:
   ```bash
   cp .env.example .env.local
   ```

4. **Запустите проект в режиме разработки:**
   ```bash
   npm run dev
   ```

## 🔒 Безопасность

Данный проект прошел аудит безопасности перед публикацией:
- Все конфиденциальные данные (API ключи, пути) вынесены в переменные окружения.
- Файлы `.env` и локальные артефакты добавлены в `.gitignore`.
- В коде используются стандартизированные заглушки для демонстрационных целей.
